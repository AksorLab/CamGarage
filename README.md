# CamGarage

An app that helps people find public parking lots and garages. It shows them on a map and gives the details drivers need before they go.

## Features

- **Map search**: find parking and garages near you or in any area.
- **Listing details**:
  - Opening hours
  - Services (e.g. car wash, repair, EV charging, security, covered parking)
  - Categories (e.g. public parking, garage, street parking, private lot)
  - Pricing (hourly, daily, monthly, special rates)
- **Filters**: by category, service, price, and whether it is open now.
- **Directions**: navigate to the selected location.

## Planned Roadmap

1. MVP: map view, listing detail page, search and filters
2. Data: admin tools and import for adding and updating locations
3. Community: user reviews, photos, and corrections
4. Owner accounts: operators manage their own listings, hours, and prices
5. Extras: live availability, favorites, multi-language support
